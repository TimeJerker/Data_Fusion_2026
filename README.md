клонируем папку себе на рабочий стол: git clone https://github.com/TimeJerker/Data_Fusion_2026.git

работаем в разных ветках, создаешь новую ветку и заходишь в нее git checkout -b <name_of_branch>
ветка main защищена от слияния, перед его совершением нужно сделать pull request, чтобы другие знали что было сделано и какие нововедении были созданы

устанавливаем себе uv: pip install uv

подтягиваем библиотеки: uv sync (uv сам создат виртуальную среду)

файл с датасетом добавляем сами и вписываем в .gitignore

получившиеся метрики и параметры записываем в mlflow
